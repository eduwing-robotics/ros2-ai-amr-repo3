# 2026-07-16 1층 전용 입출고 리프트 시나리오

## 공통 결정

- 대상 로봇은 `tb3_2`다.
- 2층 리프트 동작은 사용하지 않는다.
- 리프트 높이는 원시 `0mm`와 `6mm`만 사용한다.
- `43mm`, `50mm`, `command_scale=1.282` 보정은 사용하지 않는다.
- 모든 정밀 접근은 `40cm 정지 → 3초 대기 → 최종 삽입` 순서다.
- 40cm에서 저장한 return pose와 최종 삽입·직선 후진은 같은 command 안에서 수행한다.
- 슬롯 이탈은 저장한 40cm 위치까지 `angular_z=0` 직선 후진한다.
- 리프트 목표 높이와 `STOP` 피드백을 확인하기 전에는 다음 단계로 진행하지 않는다.

## 출고 시나리오

경로: `로봇대기장2 → 창고 A 1층 픽업 → 출고2 1층 하역 → 로봇대기장2`

1. 대기장2에서 리프트 `0mm / STOP / lower=true` 확인.
2. 마커4 기준 회전 없이 40cm까지 직선 후진 후 Nav2 전환.
3. Nav2 position-only로 `warehouse_a_approach` 이동.
4. 마커7 중앙정렬, 40cm 정지, return pose 저장, 3초 대기.
5. 리프트 0mm로 창고 A 최종 18cm까지 직선 삽입.
6. 삽입 후 리프트를 원시 6mm로 올려 화물을 픽업하고 `6mm / STOP` 확인.
7. 화물을 든 채 저장한 40cm 위치까지 직선 후진 후 Nav2 전환.
8. Nav2 position-only로 `outbound_slot_2_approach` 이동.
9. 마커6 중앙정렬, 40cm 정지, return pose 저장, 3초 대기.
10. 리프트 6mm를 유지한 채 출고2 최종 20cm까지 직선 삽입.
11. 삽입 후 리프트를 원시 0mm로 내려 화물을 놓고 `0mm / STOP` 확인.
12. 빈 포크로 저장한 40cm 위치까지 직선 후진 후 Nav2 전환.
13. Nav2 position-only로 `vehicle_2_approach` 이동.
14. 마커4 중앙정렬, 40cm 정지, 3초 대기, 최종 20cm 삽입 후 종료.

리프트 순서: `0 → 6 → 0mm`.

## 입고 시나리오

경로: `로봇대기장2 → 입고2 1층 픽업 → 창고 A 1층 보관 → 로봇대기장2`

1. 대기장2에서 리프트 `0mm / STOP / lower=true` 확인.
2. 마커4 기준 회전 없이 40cm까지 직선 후진 후 Nav2 전환.
3. Nav2 position-only로 `inbound_slot_2_approach` 이동.
4. 마커1 중앙정렬, 40cm 정지, return pose 저장, 3초 대기.
5. 리프트 0mm로 입고2 최종 20cm까지 직선 삽입.
6. 삽입 후 리프트를 원시 6mm로 올려 화물을 픽업하고 `6mm / STOP` 확인.
7. 화물을 든 채 저장한 40cm 위치까지 직선 후진 후 Nav2 전환.
8. Nav2 position-only로 `warehouse_a_approach` 이동.
9. 마커7 중앙정렬, 40cm 정지, return pose 저장, 3초 대기.
10. 리프트 6mm를 유지한 채 창고 A 최종 18cm까지 직선 삽입.
11. 삽입 후 리프트를 원시 0mm로 내려 화물을 놓고 `0mm / STOP` 확인.
12. 빈 포크로 저장한 40cm 위치까지 직선 후진 후 Nav2 전환.
13. Nav2 position-only로 `vehicle_2_approach` 이동.
14. 마커4 중앙정렬, 40cm 정지, 3초 대기, 최종 20cm 삽입 후 종료.

리프트 순서: `0 → 6 → 0mm`.

## 실행 전 필수 확인

- 리프트 시작 상태 `0mm / STOP / lower=true`.
- Movement에서 `command_scale=1.282`가 적용되지 않도록 1층 시나리오 명령은 원시 높이를 사용한다.
- lift bridge의 fresh `POS`/`DIR` 피드백이 연속 수신되는지 확인한다.
- 새 unique command ID를 사용한다.
- 사용자가 명시적으로 요청하기 전에는 주행 시나리오를 실행하지 않는다.
