# 전 존 ArUco 2단계 삽입과 리프트 적재·하역 순서 계약

# 전 존 ArUco 2단계 삽입과 리프트 적재·하역 순서 계약

## 적용 범위
입고1·입고2·출고1·출고2·창고 A·B·C·D 및 로봇대기장 도킹에 적용한다. 거리와 리프트 높이는 하드코딩하지 않고 zones.json의 존·층·작업별 보정값을 사용한다.

## 공통 접근 순서
1. Nav2 position-only로 해당 approach에 도착한다.
2. ArUco로 중앙정렬하며 마커 기준 0.40m에서 정지한다.
3. 완전 정지 상태를 3초 유지한다.
4. 작업 명령의 action(load/unload)과 level을 확인한다.
5. 리프트를 해당 존·층의 pre_insert_mm 높이로 이동하고 목표 높이 도달 응답을 확인한다.
6. 높이 확인 후에만 중앙정렬을 유지하며 존별 최종 삽입 거리까지 직선 전진한다. 기본은 0.20m이고 창고 A 등은 보정값 0.18m를 사용한다. 0.20m/0.18m 접근 자체가 삽입 단계다.

## 적재(load)
삽입 완료 후 포크가 화물 아래에 있는 상태에서 설정된 load_height_mm까지 살짝 들어 화물 하중을 포크로 넘긴다. 적재 완료를 확인한 뒤 그 높이 또는 설정된 carry_height_mm를 유지하며 저장한 approach 위치까지 각도 보정 없이 직선 후진한다. 선반·설비에서 완전히 빠져나온 뒤 carry 높이를 적용하고 Nav2로 전환한다.

## 하역(unload)
40cm 위치에서 명령받은 층의 pre_insert_mm까지 먼저 올리거나 내리고, 목표 높이 확인 후 삽입한다. 삽입 완료 후 설정된 unload_height_mm까지 살짝 내려 화물 하중을 선반으로 넘긴다. 화물이 놓였고 포크가 비었다는 완료 응답을 확인한 뒤 approach까지 각도 보정 없이 직선 후진한다. 선반에서 완전히 빠져나온 뒤에만 리프트를 안전 이동 높이로 내리고 Nav2로 전환한다. 특히 창고 A·B·C·D의 2층 작업은 40cm에서 2층 진입 높이 준비 → 삽입 → 살짝 내려놓기 → 빈 포크 직선 후진 → 완전 이탈 후 안전 높이 하강 순서를 지킨다.

## 존별 층 규칙
입고1·입고2·출고1·출고2는 level 1만 사용하며 삽입 전 진입 높이는 0mm다. 창고 A·B·C·D는 명령의 level 1 또는 level 2를 사용하고 zones.json의 해당 층 pre_insert/load/unload/carry 값을 적용한다.

## 로봇대기장
대기장 주차는 0.40m 정지 → 3초 대기 → 0.20m 삽입 → hold다. 대기장 출발은 회전하지 않고 직선 후진하며, 0.40m 안전 이격 확보 후 Nav2로 넘긴다.

## 안전 불변조건
리프트 목표 높이 미도달, 적재·하역 완료 미확인, ArUco 삽입 거리 미확인 중 하나라도 발생하면 삽입·후진·다음 Nav2 단계로 넘어가지 않는다. 40cm 안전 위치 또는 현재 안전 상태에서 FAILED/재개 가능 상태로 정지한다. 슬롯 작업 후 후진은 모든 존에서 저장한 approach까지 angular_z=0 직선 후진을 사용한다.
