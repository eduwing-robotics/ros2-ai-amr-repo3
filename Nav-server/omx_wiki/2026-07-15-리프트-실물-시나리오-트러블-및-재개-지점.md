# 2026-07-15 리프트 실물 시나리오 트러블 및 재개 지점

## 2026-07-15 실물 테스트 결과

대상 시나리오: 로봇대기장2 → 창고 A 2층 픽업 → 출고2 1층 하역 → 로봇대기장2.

### 최종 물리 결과

- 분할 복구 실행을 포함해 최종 명령은 DONE.
- 창고 A 픽업, 출고2 하역, 직선 후진, Nav2 전환, 대기장 복귀 완료.
- 최종 마커4 추정 거리 0.1975m, center_error_norm 0.0.
- 최종 리프트 위치 0mm, 로봇 IDLE, 비상정지 없음.
- 전체 무중단 재실행은 아직 미검증. 리프트 신뢰성은 다음 작업일에 다시 검증해야 함.

### 오늘 발생한 문제

1. 첫 전체 실행과 4번 단계 재개에서 43mm 명령 타임아웃:
   lift move timeout target=43.0mm cmd=55.1mm position=0.0
2. SBC lift_bridge 프로세스는 살아 있었지만 Arduino POS/DIR 직렬 응답이 멈춘 반쪽 연결 상태.
3. lift_bridge 재시작 후 자동 호밍 과정에서 음수 위치가 발행됐고, STATE 직접 요청 후 0mm 연속 피드백 복구.
4. Movement API 재시작 후 43mm 독립 검증은 ARRIVED.
5. 창고 A 픽업 후 출고2에서 6mm 명령이 유실되어 position=64mm 타임아웃.
6. API 재시작으로 command-local return_poses가 사라져 outbound2 삽입 시 approach return pose unavailable 발생.
7. 별도 command로 캡처한 return pose는 다른 resume command로 공유되지 않음. 동일 command에 40cm 캡처와 삽입/후진을 묶어야 함.
